# Three-platform Injector Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship three real graphical injector packages and publish source plus a GitHub Release.

**Architecture:** Shared Python payload validation, strict transport orchestration and Tk desktop UI. Windows uses pinned libusbK 3.1.0.0 public APIs and a bounded raw control ioctl. Android uses Java USB authorization and a JNI asynchronous usbfs trigger.

**Tech Stack:** Python 3.11, Tk, PyInstaller, Java API 35, Android NDK, libusbK.

**Spec:** docs/apps-design.md (approved in chat 2026-11-07).

## Global Constraints

- iOS is excluded; default Hekate is fixed at 6.5.4.
- Only APX 0955:7321 is selected; validate bundled files before USB writes.
- No firmware, SD, save, game or AutoRCM operations.
- USB sending is distinct from actual console boot; never claim boot success.
- Never publish signing keys, device logs, backups or local paths.

## Review Focus

- Short reads/writes must stop before triggering.
- Missing drivers/permission errors cannot be interpreted as successful triggering.
- Closing a window or Activity during transfer cannot free in-flight native USB memory.
- Frozen desktop apps must work without a source checkout or global Python.
- Android package signing and Windows DLL architecture must be verified, hardware tests listed separately.
